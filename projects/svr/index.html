Active VR / gaming project

SVR Poker

A premium social poker platform being developed across browser, Meta Quest and mobile experiences. The project combines direct poker play, immersive VR presentation, sponsor surfaces, social features and a growing interactive roadmap.

Open SVR PokerOpen Game

Protected direction

  • Meta Quest hands-first VR experience.
  • Android browser / magic-window support.
  • Stable direct-to-table experience.
  • Non-destructive modular improvements.

Current VR focus

  • Improve scene lighting and table readability.
  • Keep dealer/table interaction visually coherent.
  • Refine watch and hand presentation.
  • Protect performance and known-good baselines.
Project-manager rule: presentation upgrades must not regress stable gameplay. VR changes should be audited, isolated and verified before replacing a known-good baseline.
